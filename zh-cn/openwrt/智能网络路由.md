## 二、st-dns + st-proxy 是什么？有什么优势？

### 它们是什么？

**st-dns**：一个智能 DNS 解析器
- 就像你的私人导航，知道哪条路最近、最快、最不堵
- **核心能力 1：防劫持** - 支持 DoT 加密查询，运营商无法劫持和监听
- **核心能力 2：地区优化** - 配合 st-proxy，优先返回你能快速访问的区域 IP
- **核心能力 3：持久化缓存** - LevelDB 存储，重启也不丢，查询 < 1ms

**st-proxy**：一个会学习的智能网络代理
- 就像你的私人司机，知道哪些地方直接去，哪些地方要中转
- **核心能力 1：智能学习** - 按 IP-Tunnel 组合分析质量，记录每个 IP 通过每个节点的延迟、成功率
- **核心能力 2：质量监控** - 节点慢了？自动换。节点挂了？加入黑名单
- **核心能力 3：自动分流** - 国内网站直连，海外网站中转，全自动
- **核心能力 4：流量统计** - 追踪记录全部流量，提供详细的监控数据和可视化分析

**重要**：st-proxy 不提供代理服务，只负责智能管理你已有的代理节点。

### 对比传统方案

网络优化这事儿，市面上方案很多：

- **传统 DNS**：简单但慢，没有智能优化，容易被劫持
- **普通代理**：功能单一，不会自动学习，节点挂了你都不知道
- **智能路由器**：贵，而且不一定好用

### 核心优势

**st-dns 的杀手锏：防劫持 + 地区优化**

传统 DNS 的问题：
```
你：google.com 在哪？
运营商 DNS：给你一个被劫持的 IP（广告页面）
或者：给你一个海外远端的 IP（延迟 300ms）
```

st-dns 的解决方案：
```
你：google.com 在哪？
st-dns：
  1. 使用 DoT 加密查询，运营商无法劫持
  2. 发现你有亚洲节点代理，优先返回亚洲的 IP
  3. 结果：干净的 IP + 低延迟（50ms）
```

**st-proxy 的杀手锏：智能学习**

传统代理的问题：
```
你有 3 个代理节点（亚洲、欧洲、北美）
访问 google.com → 随机选一个 → 可能选到最慢的
节点挂了 → 你都不知道 → 继续用 → 连不上
```

st-proxy 的解决方案：
```
第一次访问 google.com：尝试所有节点，记录每个 IP-Tunnel 组合的质量
  - google.com IP1 + 亚洲节点：延迟 50ms，成功
  - google.com IP1 + 欧洲节点：延迟 150ms，成功
  - google.com IP1 + 北美节点：延迟 200ms，成功
第二次访问：直接选延迟最低的 IP-Tunnel 组合（IP1 + 亚洲节点）
持续使用：不断优化，淘汰差的组合，保留好的组合
节点故障：自动加入黑名单，避免浪费时间
```

**关键创新**：不是简单地记录"节点好不好"，而是记录"某个 IP 通过某个节点好不好"。同一个节点，访问不同 IP 的效果可能完全不同！

### 实际效果对比

**场景一：防止 DNS 劫持**

传统方案：
```
访问某网站 → 运营商 DNS 劫持 → 跳转到广告页面 → 气死
或者：DNS 污染 → 返回错误 IP → 网站打不开
```

st-dns：
```
访问某网站 → DoT 加密查询 → 运营商无法劫持 → 返回正确 IP → 秒开
```

**场景二：地区优化（这是核心）**

传统方案：
```
访问 google.com → DNS 返回海外远端 IP → 延迟 300ms → 慢
你明明有亚洲节点代理，但 DNS 不知道
```

st-dns + st-proxy：
```
st-proxy 告诉 st-dns："我有亚洲节点代理"
访问 google.com → st-dns 优先返回亚洲 IP → 延迟 50ms → 快
```

**这就是地区优化的威力：DNS 知道你的网络环境，返回最适合你的 IP。**

**场景三：智能学习（IP-Tunnel 组合优化）**

传统方案：
```
连接海外服务器 → 延迟 200ms → 卡顿 → 效率低
换个节点试试 → 还是慢 → 再换一个 → 浪费时间
```

st-proxy：
```
第一次连接 IP1 → 尝试所有节点，记录质量
  - IP1 + 亚洲节点：延迟 50ms ✓
  - IP1 + 欧洲节点：延迟 150ms
  - IP1 + 北美节点：超时 ✗
第二次连接 IP1 → 直接用亚洲节点 → 延迟 50ms
第三次连接 IP2 → 发现 IP2 + 欧洲节点最快 → 延迟 40ms
第 N 次连接 → 每个 IP 都知道最优路线 → 秒连
```

**核心优势**：不是"这个节点好"，而是"这个 IP 通过这个节点好"。精准到 IP 级别的优化！

**场景四：流量监控和分析**

传统方案：
```
不知道哪些网站占用流量多 → 不知道哪些节点用得多 → 流量超了也不知道原因
```

st-proxy：
```
实时监控所有流量 → 按域名、IP、节点统计 → 可视化展示
  - 今天访问了哪些网站？流量多少？
  - 哪个节点用得最多？
  - 哪些网站最耗流量？
  - 一目了然，心中有数
```

**场景五：重启路由器**

传统方案：
```
重启路由器 → DNS 缓存没了 → 前 10 分钟所有网站都慢 → 等缓存重新建立
```

st-dns + st-proxy：
```
重启路由器 → 缓存还在（持久化存储）→ 立即恢复满速
```

## 三、工作原理（简单说）

### st-dns 的工作流程

```
1. 收到 DNS 查询请求（如 google.com）
2. 先查缓存（LevelDB 持久化存储）
3. 缓存命中？直接返回（< 1ms）
4. 缓存未命中？根据地区选择最优上游 DNS
5. 使用 DoT 加密查询，防止劫持
6. 获取结果后存入缓存，下次秒回
```

**关键技术**：
- **DoT（DNS over TLS）**：加密 DNS 查询，防止运营商劫持和监听
- **地区优化**：配合 st-proxy，优先返回你能快速访问的区域 IP
- **持久化缓存**：LevelDB 存储，重启路由器也不怕

### st-proxy 的工作流程

```
1. 拦截网络连接请求
2. 查询目标 IP 对应的域名（问 st-dns）
3. 检查质量数据库（哪个节点最快？）
4. 自动选择最优节点（直连/亚洲/欧洲）
5. 转发流量，同时记录质量指标和流量数据
6. 下次访问时，已经知道最优路线
```

**关键技术**：
- **质量分析器**：按 IP-Tunnel 组合记录质量（延迟、成功率、稳定性）
- **智能选择**：为每个 IP 选择最优的 Tunnel，不是简单地选"最好的节点"
- **黑名单机制**：某个 IP-Tunnel 组合失败多次？加入黑名单，避免浪费时间
- **流量监控**：实时追踪所有网络流量，提供详细的统计数据和可视化分析

### 黄金搭档：1+1>2

**单独使用的局限**：

只用 st-dns：
- 能防劫持、能缓存
- 但不知道你有哪些代理节点
- 无法做地区优化，只能返回 DNS 服务器给的 IP

只用 st-proxy：
- 能智能选择节点
- 但拿到的 IP 可能不是最优的（DNS 不知道你的网络环境）
- 就像司机很厉害，但导航给的目的地不对

**配合使用的威力**：

st-dns + st-proxy 的协同：
1. st-proxy 启动时，告诉 st-dns："我有亚洲、欧洲、北美节点"
2. st-dns 解析域名时，优先返回匹配这些地区的 IP
3. st-proxy 收到请求后，为这个 IP 选择最优的 Tunnel
4. st-proxy 记录 IP-Tunnel 组合的质量，下次更快

**结果**：
- DNS 返回的 IP 是最适合你网络环境的
- Proxy 选择的 Tunnel 是这个 IP 的最优路径
- 延迟从 200ms 降到 50ms，丝滑！

**就像导航知道你的车能走哪些路，给你规划最优路线；司机根据实际路况，选择最快的开法。**

## 四、使用姿势

### 安装配置（超简单）

**适合人群**：家里有 OpenWrt 路由器的

**步骤**：
1. 在路由器上安装 st-dns 和 st-proxy 软件包
2. 打开 LuCI Web 管理界面
3. 在"服务"菜单找到 st-dns 和 st-proxy
4. **通过 Web 界面配置**（不用手动编辑 JSON 文件）
   - st-dns：配置上游 DNS 服务器、地区优化等
   - st-proxy：配置代理节点、白名单等
5. 点击"保存并应用"
6. 全家设备自动享受加速

**难度**：⭐（会用路由器 Web 界面就行，比手机 App 还简单）

**优势**：
- ✅ 有图形化 Web 管理界面，鼠标点点就能配置
- ✅ 不需要 SSH，不需要命令行
- ✅ 配置实时生效，立即看到效果
- ✅ 全家设备自动受益，一次配置终身享受

### 配置说明

**直接在 Web 界面配置，不需要手动编辑文件！**

打开路由器管理界面 → 服务 → st-dns / st-proxy → 填写配置 → 保存

**st-dns Web 界面配置项**：
- 上游 DNS 服务器（如 223.5.5.5、1.1.1.1）
- 地区优化开关（必须开启）
- DNS 协议选择（UDP/TCP/DoT）
- 缓存时间设置

**st-proxy Web 界面配置项**：
- 代理节点列表（IP、端口、地区）
- 白名单（国内网站直连）
- 并发连接数
- 超时时间
- 流量监控和统计查看

**就这么简单，鼠标点点就配好了！**
